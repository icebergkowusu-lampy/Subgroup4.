02

Lesson objectives

By the end of this lesson, learners will be able to:

  1. Recognise and classify linear and non-linear functions.
  2. Use correct function notation, such as f(x) = mx + c.
  3. Construct tables of values and interpret their graphs.
  4. Solve linear equations and simultaneous equations.
  5. Apply functions to real-life situations, such as taxi fares.
  6. Communicate mathematical reasoning clearly, both orally and in writing.
