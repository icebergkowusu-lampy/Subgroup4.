PRACTICE

Six practice questions

Work through each question. Use the hint if you get stuck, check your answer, then reveal the worked solution to confirm your reasoning.

Question 1

Is y = 4x + 7 linear or non-linear?

Look at the highest power of x.
x has power 1 and the rate of change is constant — the graph is a straight line, so it is linear.

Question 2

Classify y = x² + 3.

What power is x raised to?
x is squared, so the graph is a curve, not a straight line — it is non-linear.

Question 3

If f(x) = 2x + 3, find f(5).

Substitute 5 wherever x appears.
f(5) = 2(5) + 3 = 10 + 3 = 13

Question 4

Solve 3x + 9 = 18.

Subtract 9 from both sides first.
3x = 9 → x = 3

Question 5

Solve simultaneously: x + y = 7 and x − y = 1.

Add the two equations to eliminate y.
2x = 8 → x = 4, then y = 7 − 4 = 3 → x = 4, y = 3

Question 6

A taxi charges GH₵10 plus GH₵5 per kilometre. Write a function for total cost C after travelling x kilometres.

The fixed charge is added to the variable cost per kilometre.
C = 5x + 10
