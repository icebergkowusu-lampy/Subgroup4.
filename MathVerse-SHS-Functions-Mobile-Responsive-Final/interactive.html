INTERACTIVE LAB

Explore functions with real tools

Four interactive resources for exploring linear and non-linear functions — two external graphing tools, an instructional video, and a custom canvas grapher built for this project.

1

GeoGebra — graphing calculator

Use GeoGebra's free graphing calculator to plot linear functions such as y = 2x + 1 and non-linear functions such as y = x². Try changing the gradient and intercept to see how the graph moves.

If the embedded tool does not load on your device, open it directly: geogebra.org/graphing ↗

Source: GeoGebra Graphing Calculator, GeoGebra GmbH.

2

Desmos — graphing calculator

Desmos is another excellent free graphing tool. Plot the table-of-values example from the lesson, y = 2x + 1, alongside a non-linear function such as y = x² + 4 and compare their shapes.

If the embedded tool does not load on your device, open it directly: desmos.com/calculator ↗

Source: Desmos Graphing Calculator, Desmos Studio PBC.

3

Instructional video

Watch this short video on recognising linear and non-linear functions from tables and equations, then return to the lesson's Curriculum Activities to practise.

Backup link: youtube.com/watch?v=Pt-Tn6L60-o ↗

Source: "Linear and nonlinear functions (example 1)," Khan Academy, youtube.com. Free educational content.

4

Custom canvas function grapher

This grapher was built from scratch with HTML Canvas for this project (no external graphing library). Adjust the vertical shift c to explore the non-linear function f(x) = x² + c.

0

f(x) = x² + 0

Notice the curve, not a straight line — and that the rate of change is not constant, confirming this is a non-linear function.
